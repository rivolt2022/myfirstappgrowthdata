# 2026 2회차 예시 대시보드 — 극지식물 개체별 생육 차이 분석

1회차 실습 흐름(데이터 점검 → 환경 분석 → 개체별 생육 차이 → 관계 분석 → 잘 자란/덜 자란 개체 비교 → 예측 모델 → 결론)을
그대로 웹 대시보드로 옮긴 예시입니다. 평균·분산만이 아니라 이상치, 상관(r·p값), 그룹 비교(Welch t검정), 회귀 예측까지 보여줍니다.

## 폴더 구조
```
streamlitapp_2026/
├── main.py            # 대시보드 (7탭)
├── requirements.txt   # streamlit, pandas, numpy, plotly
└── data/
    ├── 송도고등학교_환경데이터.csv      # 2026 실제 실습 데이터
    └── 송도고등학교_생육결과데이터.csv
```

## 탭 구성 (1회차 보고서 흐름)
| 탭 | 1회차 실습 단계 | 내용 |
|---|---|---|
| 📖 실험 개요 | (1) 데이터 파악 | 팀 가설(사이드바 입력), 지표 카드, 데이터 점검(기간·간격·결측·빠진 개체번호·IQR 이상치) |
| 🌡️ 환경 변화 | (2) 환경 분석 | 요약 통계(CV 포함), 항목 선택 날짜별·시간대별 그래프, 전반부 vs 후반부 |
| 📊 개체별 생육 | (3) 개체별 차이 | 최대·최소 개체, 기초 통계(분산·CV·최대/최소), 히스토그램·상자그림, 개체 순위 |
| 🔗 관계 분석 | (3) 상관 | 상관계수 히트맵, 생중량과의 r·p값 표, 산점도(X축 선택) |
| 🏆 그룹 비교 | (4) Top/Bottom | 기준 항목 선택, 상위·하위 25% 평균±표준편차, Welch t검정 p값, 지상부÷지하부 비율 |
| 🔮 예측 모델 | (5) 예측 | 예측 항목·설명 항목 선택, 회귀식, R²·MAE·5겹 교차검증, 실제 vs 예측, 슬라이더 예측 |
| 📝 결론 | (6) 보고서 논의 | 가설, 데이터로 확인한 사실(자동 요약), 연구의 한계 |

## 2026 수정 내역 (이전 예시 코드 대비)
- 학교명 하드코딩 제거: 파일명 앞부분(예: 송도고등학교)을 제목에 자동 표시
- 열 고정 제거: 학교마다 다른 열(지상부·지하부 질량, 수온, CO2, ph·ec 없음 등)을 자동 인식해 분석
- 결측값이 있는 환경 데이터(센서 미측정 구간) 처리, 측정 간격 자동 계산
- 표준편차를 1회차 보고서와 같은 표본표준편차(n−1)로 변경
- 관계 분석·그룹 비교(p값)·예측 모델·결론 탭 추가 (scipy·statsmodels 없이 numpy로 계산)
- 원자료에 없는 EC 단위(dS/m) 표기 제거

## 다른 학교 데이터로 바꾸는 방법
`data/` 안의 CSV 2개를 자교 파일로 교체합니다. 파일명에 "환경" / "생육"만 들어 있으면 인식하고, 제목의 학교명도 자동으로 바뀝니다.
